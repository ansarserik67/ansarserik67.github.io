# MyLesson — live static site

Published build of [mylesson](https://github.com/ansarserik67/mylesson).

This repository holds only the exported output of `next build`, served by
GitHub Pages at https://ansarserik67.github.io/.

- `_next/` is the hashed JS/CSS/font bundle
- `index.html` is the landing page
- `app/`, `parents/`, `onboarding/` are the app routes
- `.nojekyll` disables Jekyll so `_next/` is served untouched
